# 02 · 技术架构文档

## 一、技术栈

| 层 | 选型 | 理由 |
|---|---|---|
| 语言 | TypeScript (strict) | 大型状态机没有类型等于裸奔 |
| 构建 | Vite 7 | 零配置、热更新快 |
| 渲染 | Canvas 2D 原生 API | 数百单位60帧无压力；接口留有平移PixiJS(WebGL)的余地 |
| UI | DOM 覆盖层（HTML+CSS） | 菜单/按钮用DOM比Canvas UI快十倍开发 |
| 依赖 | **零运行时依赖** | 渲染/引擎全手写，防止被三方库绑架 |
| 测试 | 自研无头模拟（selftest + tournament） | AI对打+日志断言，改代码11秒出回归结论 |

## 二、核心设计原则（立柱，别拆）

1. **模拟与渲染彻底分离**：`src/sim/`纯逻辑（不碰DOM/Canvas），固定60Hz推进；`src/render/`每帧读模拟状态画图。收益：无头自测、AI锦标赛、录像回放皆成可能。
2. **数据驱动**：兵种/建筑/AI参数全在数据表，加内容=加数据+一个画法函数。
3. **确定性向**：种子随机（mapgen）、固定时间步——为录像回放/联机锁步留路。
4. **触屏基因**：Pointer Events统一鼠标/触摸。
5. **日志即验收**：sim层全事件埋点，selftest对日志断言——AI改动跑一遍即回归。

## 四、关键子系统设计

### 寻路（astar + movement）
- 8方向A*二叉堆；**高度感知**：同层直走、跨层必须坡道且只跨1层、斜向禁穿缝
- 寻路预算24次/帧，超出进等待队列；追击限频0.5s、失败限频1s
- LOS抄近路（采样线逐段canStand）；分离推挤走空间哈希+滑动修正

### 战斗（combat）
- 错峰索敌（每12帧/实体，按ID错开）；idle主动追击、move只打射程内、hold绝不追、attackMove沿途主动交战打完续路
- 投射物追踪制（目标死亡飞向最后位置）；榴弹溅射+最小射程（贴脸哑火）
- 高地加成：每层优势射程+8%伤害+10%（低打高反向衰减）
- **缴获**：击杀带bounty目标→资源入库（狩猎/剿蛮族的经济激励）

### 经济（economy + gather）
- 双轨：人工采集（工程车2.5/s载货10自动回仓）vs 自动机（1.0/s进缓冲仓再转运）
- 全资源共享存储上限（HQ500+仓库500/座）；满仓自动机停机、工人扛货等位
- 伐木/采矿消耗地图储量，采完变草地（渲染脏标记+小地图同步）

### 战争迷雾（fog）
- 三态：0未探/1已探/2可见；每15帧重算；高地视野+1格/层

### AI指挥官（ai.ts + ai-config/priority/tactics）
- **快照式思考**：每thinkSec秒单次O(n)扫描生成局势快照，战术全部读快照
- **生产优先级**：`基础aiPriority × 性格权重 × 缺口系数`排序（RW aiPriority心法移植）
- **性格×4**（莽夫/乌龟/种田/均衡）：权重表+建筑目标倍率+波次倍率
- **难度×4**（轻松/标准/困难/噩梦）：经济倍率/思考频率/波次节奏/战术解锁阶梯
- **战术×7**（可独立开关）：集火/撤退止损（锁定防横跳）/保炮车/抢高地/围魏救赵/断矿/克制配兵
- 满仓总攻：库存触顶+兵力达标→倾巢而出（8秒冷却），杜绝后期呆滞

### 渲染（render/*）
- **伪3D地形**：格子按高度抬升14px/层、南向岩壁、坡道斜纹、分层草色
- **实体深度排序**：建筑+单位合并按屏幕深度绘制，遮挡正确
- **DPR基座**：每帧自建系统缩放变换（多屏/缩放屏点击对齐的关键）
- **范围圈**：选中显示视野白虚线圈+琥珀射程圈+红色最小射程圈
- 地形整图预渲染offscreen，脏地块局部重绘；迷雾低分辨率画布放大（软边）

### 程序化贴图（sprites.ts）
- 运行时离屏Canvas绘制+永久缓存（key=兵种_阵营_部件）
- 单位=车体+炮塔双层独立旋转；阵营=调色板换色；中立=专属配色
- 调色板/尺寸规范见04文档

## 五、测试与验收闭环

| 工具 | 用途 | 耗时 |
|---|---|---|
| `?selftest=1` | AI对打5分钟+日志断言8项+专项检查（采集/地形/上限） | ~0.5s |
| `node tools/tournament.mjs` | 四AI锦标赛（双擂台60分钟），难度/性格差异化量化对比 | ~11-60s |
| `npm run build` | tsc全量类型检查+生产构建 | ~1s |
| 浏览器自动化 | 真实点击/截图目检（哈仔亲手玩） | 按需 |

**规矩：任何AI/数值改动，跑一遍selftest；任何战术改动，跑一遍锦标赛对比战报。**
