# 10 · 中立生态与动物AI设计案

> 状态：**设计定稿，待开工**。建议里程碑 **M4.2（v0.17）**——排 09 装甲重构之后；本稿文件域独立（`sim/neutral.ts` 为主），小灶一份，随时可插队，不与 08/09 抢灶台。
> 定位：把动物园从"会动的资源罐头"升级成**有行为的旷野**——猎物会怕、捕食者会追、猎杀有时机、鹿群有繁衍。
> 参照声明：帝国系野生动物**没有繁殖**（消耗型地图资源），本稿的繁殖是自家发明（为种田路线供给可再生蛋白质）；"赶鹿"微操致敬帝国4（鹿群被驱赶进自家庭院）；腐烂致敬帝国2/4猎尸衰减。

---

## 设计红线（四条）

1. **一切锁死 owner 2 中立侧**——对战 AI、玩家经济、战斗管线零波及（近战结算除外，见四）
2. **全程确定性**——禁随机数，沿用 `id/tick` 混淆伪随机（selftest 友好，现有游荡代码同款纪律）
3. **不新增资源类型**——腐烂只在 bounty 缴获上做文章，不开新资源
4. **狼不脱家园**——拴绳机制保证捕食者永远回得来，禁止被风筝到天涯海角

## 一、现状诊断

| 现状（neutral.ts / units.ts） | 病情 |
|---|---|
| 鹿：只有**挨了枪**（hp<max）才逃，8格侦测、逃6格 | 没有"被接近就怕"的 FID，赶鹿微操不存在 |
| 狼：`hold` 守窝、绝不追击，敌人进射程才咬 | 是炮台不是狼；没有领地、没有追击、没有狼群 |
| 狼攻击 = 90码子弹弹道 | 假近战，视觉违和 |
| 击杀瞬间 bounty 全额入账 | 没有腐烂，猎杀没有时机艺术 |
| 鹿杀一只少一只 | 一次性罐头，与种田/和平路线脱节 |

> 术语卡：**FID**（Flight Initiation Distance，逃跑起始距离——动物行为学真术语）；**家域**（home range，出生锚点周边领地）；**拴绳**（leash，追击不得离家域过远）。

## 二、猎物状态机（鹿）

```
游荡（现版确定性游荡不变）
  └─ 敌对单位（非owner2）进入 6 格 → 警戒：停下、面向威胁
        └─ 进入 4 格 或 受到伤害 → 逃窜：沿威胁反方向狂奔 8 格 → 回游荡
```

- 逃跑方向 = **威胁反方向**——玩家绕到鹿群身后驱赶，即可把整群鹿赶向任意方向 → **"赶鹿"微操免费解锁**（帝国4同款，引擎行为自动涌现，无需专门编码）
- FID 常量进 config：`DEER_ALERT_RADIUS = 6` / `DEER_FLEE_RADIUS = 4` / `DEER_FLEE_DIST = 8`（格）

## 三、捕食者状态机（狼）

```
家域巡逻（homeX/Y 半径 5 格内游荡，现版逻辑）
  └─ 非owner2单位进入家域 5 格 → 群体仇恨：同锚点全部狼一起转入追击
        └─ 追击最近入侵者
              └─ 自身离 homeX/Y 超过 8 格 → 拴绳触发：放弃目标、返回家域
```

- **群体仇恨**：一狼叫，全窝上（现状单打独斗的修复）
- **拴绳**：防风筝——拉扯狼的部队把狼引离家域 8 格，狼自动断追回家，回程无敌（不索敌）到家再恢复
- 常量：`WOLF_TERRITORY = 5` / `WOLF_LEASH = 8`（格）

## 四、真近战

- 狼咬改为**真近战**：射程 24px（约0.75格）、**无弹道**（射程内直接结算伤害+扑咬动画），替换现有 bullet 假近战
- 实现口子：`WeaponDef` 新增 `melee: true`（或 projectile 联合类型加 `'melee'`），combat 结算时近战武器不生成 projectile 实体、射程校验放宽到贴身
- 王国将来若出近战兵种（狼骑 v2）直接复用此口子

## 五、腐烂：猎杀的时机艺术（简化版主案）

```
击杀野物 → 立即入账 bounty 的 50%（保底血汗费）
        → 剩余 50% 挂在尸体上，同阵营任意单位走近尸体 3 格内自动拾取
尸体份额随时间衰减：每 10 秒 -25%（按原始 bounty 计），40 秒后蒸发
```

- 快打快收：击杀后部队顺路收割满额；远程狙完就跑 → 只拿保底，剩余喂时间
- **自动拾取**零指令（符合本作哲学），不存在"工人收尸"的新操作
- v2 备选（完整尸体采集）：尸体成为可右键采集的微型资源点（真·帝国流程）——等将来有采集闲工再说
- 常量：`CARCASS_DECAY_STEP = 10s / -25%`、`CARCASS_PICKUP_RADIUS = 3格`

## 六、繁殖：鹿群的确定性繁衍（自家发明）

```
条件：鹿群（同 homeX/Y）成年鹿 ≥ 2 且 群内数量 < 5 且 全图鹿总数 < 上限
节奏：每 90 秒判定一次（(tick + 群id×常数) % 5400 === 0，确定性）
产出：在群锚点附近 findFree 刷新 1 只小鹿（数值=成鹿，v2 可做幼体成长期）
```

- 全图鹿上限 = 初始数量 + 4（防爆炸）
- **狼不繁殖**——捕食者压力保持恒定；蛮族掠袭者仍由营地刷（现版不动）
- 设计意图：鹿从"一次性罐头"变"可持续蛋白质"，喂饱 08 的和平/种田路线

## 八、selftest 用例（确定性）

1. 鹿在 6 格转入警戒、4 格或受击逃窜、方向=威胁反向
2. 单狼被触发 → 同窝全体转入追击（群体仇恨）
3. 狼被引离家域 8 格 → 断追返回，回程不接战
4. 近战：狼咬不产生 projectile 实体
5. 腐蚀：击杀即得 50%；尸体份额 10s/20s/30s/40s 按 75%/50%/25%/0% 被拾取
6. 繁殖：群≥2 时 90 秒 +1，群 5 封顶、全图上限封顶，两倍速模拟下计数精确
