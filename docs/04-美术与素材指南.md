# 04 · 美术与素材指南

## 一、方案结论（讨论定案）

**主食：运行时程序化生成；配菜：CC0 现成素材。**

- 为什么不全套网上找：实测 Kenney Top-Down Tanks（业界最知名免费RTS包）画力上限≈圆角矩形+圆，
  与程序化生成五五开；且无建筑/空军/魔法阵营内容，东拼西凑必风格分裂
- 为什么程序化是主食：零版权风险、双阵营风格统一、改参数即重生成、AI全程闭环维护
- 外部素材只收风格无关的通用件（子弹/烟雾/爆炸）

## 二、运行时生成管线（render/sprites.ts）

```
getUnitSprites(defId, owner)  →  { hull: Canvas, turret: Canvas }   // 缓存key: `${defId}#${owner}`
getBuildingSprite(defId, owner) → Canvas
getTerrainTile(kind, variant) → Canvas    // 地块带 hash 噪点变化
```

- 生成在离屏 Canvas，首次调用时绘制并永久缓存
- 单位两层结构：**车体（随移动方向旋转）+ 炮塔（独立瞄准旋转）**
- 阵营差异 = 调色板换色（见下）

## 六、绘制规范（给未来的自己）

- 世界比例：格 32px；步兵半径8、坦克12、建筑2~3格
- 单位贴图尺寸 = 直径×1.6 向上取偶数，留旋转出血
- 所有贴图朝向：**车体朝右(+X)，炮管朝右**，渲染时 rotate(实际角度)
- 投射物贴图朝上（Kenney 规范），渲染时 rotate(角度+90°)
- 新增兵种步骤：`data/units.ts` 加数据 → `sprites.ts` 加两个画法函数 → 完事
