# 09 · 装甲重构与晨曦王国设计案

> 状态：**设计定稿，待开工**。对应里程碑 M3.5（v0.14）/ M4.0（v0.15）/ M4.1（v0.16）。
> 定位一句话：**给战争系统换心脏（上卷），再在新地基上种一个可玩阵营（下卷）。**
> 方法论：减伤阶梯与双命制参考星际2（Light/Armored）与魔兽3攻防矩阵的紧凑版；破甲=帝国时代"类别加成"的极简化身；双阵营各自成军——不同势力打不同的战争，兵种不要求一一对应，平衡以"同造价强度期望拉平"为唯一标尺。只抄被验证过的。
> 依赖：与 08（金币与商路，M3.2~M3.4）**并行安全**，但两者都会动 `ui/hud.ts`——后落地方负责 rebase 面板改动。M4.1 的纪元对应皮依赖 08 的 M3.3（纪元）落地。

---

## 设计红线（七条，开工后任何改动不得越过）

1. **破甲倍率是全局常量**（`ARMOR_PIERCE_MULT = 2`，进 config）——任何武器数据表禁止私改倍率，想强就改单发伤害
2. **破甲来源每阵营 ≤ 2**——破甲一泛滥，"重甲就是好"就变"重甲就是纸"
3. **不新增第三种护甲类别**——轻/重二元锁死，加类别=全矩阵翻修
4. **王国 v1 无海军**——海兽留 v2
5. **巨龙禁止 boss 化**——必须可被"防空塔+机枪海"解，天敌写入数据表而非嘴上
6. **经济同规（公平起点）**：双方采集/建造/存储规则与数值一致；军事单位各自成军、不要求一一对应——平衡唯一标尺=同造价强度期望拉平
7. **掉甲必须可感知**——碎片特效+音效+飘字，禁止静默掉甲；系统玩家看不见=没做

# 上卷 · 装甲与攻击系统（全阵营地基手术）

## 一、攻击三分类 + 属性贴纸

原六种弹种（bullet/shell/cannon/fire/missile/explosive）**全部合并为三个攻击类别**：

| 类别 | 是什么 | 现有武器归并 |
|---|---|---|
| **轻攻击** | 步枪/机枪/弓弩/近战 | bullet、fire（喷火兵） |
| **重攻击** | 坦克炮/榴弹/导弹/炮舰 | shell、cannon、explosive、missile |
| **破甲**（标签） | 专拆装甲的稀有货 | 坦克主炮、机甲炮（科技）；弩炮（王国） |

**属性贴纸**（与类别正交，可自由叠加）：`溅射` `点火（持续灼烧DoT）` `对空` `最小射程` `对空专职(airOnly)`。

**迁移对照**：`fire` 弹种取消独立类别，喷火兵=轻攻击+点火属性；龙息=重攻击+点火+溅射。

## 二、减伤表（全游戏唯一的克制链）

| 挨轻攻击 | 挨重攻击 | 挨破甲 |
|---|---|---|
| **轻甲** 85% | 轻甲 100% | 轻甲 100% |
| **重甲** 40% | 重甲 85% | 重甲 100% |

- 减伤只作用于**血**，永远不低于双方armor状态判定（见下）
- 破甲列对血永远全额，且唯一能削减装甲池（见四）
- 单调阶梯是**故意的**："重甲就是比轻甲好"成立的前提=甲出厂即定、绑阵营绑生态位（钢铁全重甲贵而慢，王国全轻甲廉而快），不存在同岗位二选一

## 三、双命制与结算管线

每个战斗单位两条命：**装甲池（外）+ 生命值（内）**。一次攻击的完整结算顺序：

```
1. 护盾层（若有）：护盾池先吃全额伤害（现 shieldGen 机制不动）
2. 溢出进入装甲管线：目标装甲池 > 0 → 查减伤表得百分比
3. 扣血 = 伤害 × 表格百分比；装甲池 = 0 → 全额扣血
4. 装甲池结算：仅破甲攻击可扣（见四）；普通攻击对装甲池零影响
5. 属性结算：溅射/点火按各自规则（点火DoT每跳按源类别走减伤表）
```

- **掉甲**：装甲池归零瞬间，减伤表对该单位**作废**，之后所有攻击全额伤血。碎片特效+音效+飘字
- **不朽甲**：数据表 `armor: -1` = 装甲池无限（预留：08 的奇观、总部要塞化用；不写 99999 魔数）
- 实体新增字段：`armorHp / armorMax / lastDamagedAt`（两浮点一时间戳，性能可忽略）

## 四、破甲规则（夺门之钥）

```
破甲一击：血扣 = 单发伤害 × 100%（无视减伤表）
         甲扣 = 单发伤害 × 2（ARMOR_PIERCE_MULT，全局常量）
普通攻击：只按减伤表扣血，装甲池一根毛都碰不到
```

- 破甲标签**只准贴给重攻击**类武器；破甲与溅射互斥
- 破甲打无甲/已掉甲目标=普通重攻击（100%），无惩罚无加成
- **每阵营破甲来源 ≤ 2**：科技=坦克主炮+机甲炮；王国=弩炮（独苗）

**打击感样表（打 140血+300重甲 的坦克，单挑）：**

| 来打的是 | 效果 | 耗时 |
|---|---|---|
| 机枪（6伤/0.7s，轻攻击） | 血扣2.4/发，甲永不掉 | ≈41秒（磨到天荒地老） |
| 坦克炮（22伤，重攻击） | 血扣18.7/发，甲不掉 | ≈8秒（前提是你也有坦克） |
| **弩炮（35伤/2.2s，破甲）** | 血扣35/发，**甲扣70/发** | ≈18秒（5发剥甲，再4发送走） |

## 五、状态标签预留注册表（只留坑位，不做效果）

武器数据结构新增可选字段：`status: { kind, dur, potency }`，注册表五个坑位：

| 标签 | 含义 | 状态 |
|---|---|---|
| `burn` 火焰灼烧 | 持续灼烧DoT | **已实装**（喷火兵/燃烧区），收编进本框架 |
| `shock` 雷电 | 预留 | 无效果，解析不报错 |
| `poison` 中毒 | 预留（克血肉） | 同上 |
| `malfunction` 机械破坏 | 预留（中毒的构装版，王国反科技武器坑位） | 同上 |
| `freeze` 冰冻 | 预留 | 同上 |

**DoT 通用律**（burn 立即生效，其余预留）：每跳伤害按源武器类别走减伤表；**每跳重置目标脱战计时**（见六）——DoT 天克再生。

## 六、再生：三十息律（王国专属）

```
每次受到实际伤害（HP减少）→ 脱战计时归零
计时满 30 秒 → 开始回血：每秒回复最大血量的 2%
回血途中再次受伤 → 停止回血，计时归零重来
```

- 30 秒门闩把再生从"战斗内奶量"变成**战役间恢复**：狼撤回林子舔伤口，舔够了再出来
- 0 伤害的命中**不**清零计时；DoT 每跳清零（DoT 是再生的天敌）
- 再生**只回血不回甲**——王国单位的小甲池被剥了就永久没了，补新的
- 预示价值：回血需要**安全的地面**→地图控制价值上涨；科技方的反制=往人家疗养区派侦察兵
- 实现模版：照抄护盾 `shieldHitAt` 脱战回充的计时器模式（`lastDamagedAt`）
- AI 便签：王国 AI 撤退后必须真的拉开距离苟满 30 秒再接战（复用撤退锁定逻辑）

## 七、数值迁移（科技方全员重平衡）

**迁移口诀**：
- 重甲载具：新血 ≈ 旧血 × 2/3，新甲池 ≈ 旧有效EHP ÷ 3
- 轻甲单位：新血 ≈ 旧血 × 85%，新甲池 ≈ 旧血 × 15%
- 防御建筑：甲池给大（墙=真正的墙），血给中
- 平民（农夫）：无甲

## 八、修甲（阵营分家）

- **科技**：工程车修理扩展为**甲血双修**（现有修理管线扩展，v1 仍免费）
- **王国**：无修甲——血肉靠三十息再生，甲薄掉了就掉
- 一句话：**钢铁靠车间，血肉靠时间**

## 九、表现层

- 掉甲：碎片飞溅特效+金属碎裂音效+「甲碎！」飘字（复用 fx mark）
- 再生指示：脱战回血激活时血条旁绿点呼吸闪烁（玩家得知道"在回"）
- 护盾表现维持现状（能量层视觉）

## 十、AI 适配（缺口打分机加一行）

- 快照扩展：己方破甲火力占比 / 敌方重甲单位占比
- `foeHeavyShare > 25% 且 己方破甲占比 < 15%` → 破甲单位权重 ×2（克制配兵战术的延伸）
- 其余战斗逻辑零改动（伤害结算在 combat.ts 内部闭环）

## 十一、selftest 用例（上卷，确定性）

1. 减伤：重甲挨轻攻击，血扣40%、甲池纹丝不动
2. 破甲两段：血吃全额 + 甲池扣 伤害×2
3. 掉甲：池归零后所有来型全额伤血
4. 不朽甲 `armor:-1` 永不掉甲
5. 三十息：第29秒受击计时重置；满30秒启动2%/s回血；点火DoT每跳重置计时
6. 工程车双修：甲与血同速率恢复
7. 护盾顺序：护盾先吃全额，溢出才进装甲管线

# 下卷 · 晨曦王国（新阵营，长在新地基上）

## 十二、阵营身份卡

**钢铁联邦=驯服物理（钢板/火药/流水线），晨曦王国=驯服生命（血肉/灵兽/符文）。**

| | 钢铁联邦 | 晨曦王国 |
|---|---|---|
| 护甲 | 全重甲+厚甲池 | 全轻甲+薄甲池 |
| 耐久分布 | **前置**（甲在就硬） | **后置**（三十息再生，需安全地面） |
| 数量 | 贵慢少 | 廉快多 |
| 强项 | 正面推进/守家/海军/修甲续航 | 游袭骚扰/扩张/再生续航/破甲犀利 |
| 死法 | 被破甲剥甲处决；被放风筝拖垮经济 | 被机枪弹幕收割；再生窗口被持续火力掐断 |

**克制链总图**：`王国兵海 →(收割) 科技机枪弹幕 →(剥甲处决) 王国弩炮 →(贴脸撕碎) 科技快切机动 →(消耗) 王国再生……` 循环克制，无无敌链。

**公平锚（平衡审计标准）**：同造价两军对上"对方标准编制"时总有效血量期望拉平（按**袭击战模型**计算，非阵地战——三十息在连续强压下约等于零）。科技的技术表达=走位与修甲节奏；王国的技术表达=骚扰时机与再生循环。
