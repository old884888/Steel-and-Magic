## 设计红线（六条）

1. **节奏闸门**：一局 15~25 分钟，任何内政系统必须"可感知且可忽略"——新手无视全部内政、纯爆兵也能赢标准 AI
2. **惩罚带宽**：内政只减益不致死——民心/卫生永不直接杀死单位，**死亡螺旋禁令**
3. **军事是终审法官**：内政的价值必须能用"它让我的坦克多两辆"度量；AI 该来杀你还是来杀你
4. **无随机事件**（08 红线延续）
5. **确定性**：人口增长/流失全用计时器，selftest 可锁行为
6. **每阶段完整可玩**：M5.0/5.1/5.2 每次交付游戏必须完整可赢，禁止"半国状态"跨版本

## 一、心跳总图（三条循环咬合成一个国家）

```
【人口循环】民居(容量) → 待业居民 → 转职上岗(岗位建筑) → 产出入小缓冲 → 搬运工扛去仓库 → 税+军饷
【民心循环】卫生覆盖 + 食物充足 + 税率舒适 → 民心 → 高:吸引移民+ / 低:居民流失-
【战争循环】待业居民 →训练→ 兵籍(民兵/步兵·单行道) ；载具=资源+人口(乘员征召)
```

## 二、居民系统（骨髓）

### 2.1 两个数值
- **人口容量**：民居 +5/座、帝国中心 +5（开局自带，住得下初始人口）
- **实际人口**：开局 **5**；由民心驱动增长/流失（见 2.3）

### 2.2 三种状态
| 状态 | 在哪 | 怎么进出 |
|---|---|---|
| 待业 | 住民居/帝国中心 | 岗位建筑点"+"分配即迁居上岗；被分配时从住房走出来走到岗位 |
| 在岗 | 岗位建筑 | 阵亡=人口−1+岗位空缺（v1 纯手动补员；"自动补员"开关 v1.1） |
| 兵籍 | 步兵营训练产出 | **单行道**：入伍即脱产，阵亡=人口永久−1 |

### 2.3 民心（v1 构成，名字叫民心不叫健康）
```
民心(0~100) = 40×卫生覆盖(被罩住的民居占比) + 40×食物充足率 + 20×税率舒适度
  食物充足率：食物库存 ≥ 人口×10 时满分，线性衰减至 0
  税率三档：低税(舒适+100) / 中税(+60) / 高税(+20)
增长：民心 ≥ 60 且 人口<容量 → 每 30 秒 +1
流失：民心 ≤ 30 → 每 60 秒 −1；地板=5（初始人口不走光）
战争豁免：敌军入侵本方建筑期间，流失暂停（不双重惩罚）
```
### 2.4 人口税（08 红线正式重开）
金币收入 = 人口 × 档位系数（低1/中2/高3 金/人/分钟）。**拉税换钱、掉民心跑人**——每天的选择题。

## 五、AI 重构（工作量 1:1:3——一分逻辑、一分用例、三分调平）

### 5.1 分蛋糕仲裁（第一次真课题）
```
每轮思考：
1. 岗位空位 → 从待业池补员（最缺经济的岗位优先：食物>木>矿）
2. 待业池 ≤ 储备3 → 禁止军事训练消耗居民（储备滞回，防抽搐）
3. 待业 > 3 且军队低于波次目标 → 训练
4. 人口 < 容量且民心高 → 无事可做等移民；民心低 → 查缺补漏（卫生/食物/降税）
```
### 5.2 民心管理
- 无覆盖民居数 > 0 → 净水站缺口加权（复用缺口打分）
- 食物充足率低 → 农庄补员/铺田加权
- 税率按性格：莽夫高税（快钱快攻）、种田低税（人口滚雪球）、均衡中税
### 5.3 难度语义不变
`economyMul` → 工人产出乘数（高难度明示补贴照旧）
### 5.4 邋遢即拟人
内政惩罚只有 −15%~−25%，AI 稍微不讲卫生死不了——**惩罚带宽天然给了 AI 犯错余地**，不追求 AI 内政满分。

## 七、selftest 用例（确定性）

1. 转职：住房5人，农庄+2 → 2居民迁居变农民，住房余3，农庄缓冲开始进账
2. 阵亡回补：农民阵亡 → 人口−1、岗位空缺标感叹号
3. 民心：满足条件30秒+1；低民心60秒−1；地板5；入侵期间流失暂停
4. 税：三档金币收入数值精确；高税民心减成生效
5. 搬运工：缓冲>50%触发扛运入库；半径外建筑不理；最满优先
6. 建造表演：放置扣款→车取料→建成，账目平衡
7. AI仲裁：双倍速10分钟模拟，岗位恒有人、待业≥3、无振荡
8. **survival**：AI 全系统（民心/税/岗位/军事）自给自足 15 分钟，粮食不归零、人口不低于地板、军队持续产出
