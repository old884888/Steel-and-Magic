# 08 · 纪元与商路设计案（金币 / 商队 / 纪元 / 奇观）

> 状态：**设计定稿，待开工**。对应里程碑 M2.10 ~ M2.12（v0.10 ~ v0.12）。
> 目标：接住"不想一直打架"的玩家——种田运营成为与军事征服并列的完整获胜路线。
> 方法论：**只抄被验证过的**。奇观/时代抄帝国时代，金币购买抄文明，数据驱动与难度诚实抄铁锈（已在用）。
> 设计底线（四条红线，开工后任何改动不得越过）：
> 1. 三资源（木/食/矿）的采集与存储规则**一个字不改**，金币是浮在上面的流动性，不是第四种矿。
> 2. 现有军事流节奏不变：莽夫流开局一分钟被任何人挑不出毛病，时代不硬锁旧内容。
> 3. 标准档 AI 与玩家完全对等的诚实原则延续：经济倍率不作用于金币。
> 4. **不引入随机事件卡**（v0.9.1 已移除，与游戏主题不符，永不复活）。

## 一、全局游戏流程（新系统接入后的整局节奏）

### 1.1 一局游戏的时间轴（标准对局约 15~25 分钟）

```
 开局(0~3min)          发育期(3~8min)           中盘(8~14min)            终盘(14~20min)
┌────────────┐    ┌───────────────┐    ┌──────────────────┐    ┌─────────────────────┐
│ 拓荒纪元     │    │ 双轨经济全开    │    │ 工业纪元(约5~7min) │    │ 钢铁纪元(约10~12min)  │
│ HQ+工程车    │───▶│ 蛮族劫掠敲门    │───▶│ 军事流: 波次互攻    │───▶│ A 军事流: 攒兵推HQ    │
│ 三资源+保底  │    │ 蛮族抉择:       │    │ 种田流: 商路成网    │    │ B 奇观流: 盖纪念碑    │
│ 军事开/商路开│    │  剿? 还是养?   │    │ 交叉施压: 断矿/宰商队│    │  → 90秒加冕倒计时    │
└────────────┘    └───────────────┘    └──────────────────┘    └─────────────────────┘
                                                                     ↓
                                              胜负三出口: HQ被拆 / 加冕完成 / 奇观被拆退回军事流
```

### 1.2 每个阶段的核心决策问题（种田玩家的"战争替代品"）

| 阶段 | 军事流玩家在想什么 | 种田流玩家在想什么 |
|---|---|---|
| 开局 | 兵营多早下？ | 商贸站选在哪条路线上？近而稳还是远而肥？ |
| 发育期 | 第一波什么时候凑齐？ | 蛮族剿了拿缴获，还是通商养着当客户？ |
| 中盘 | 打哪？断矿还是围魏救赵？ | 金币花哪：应急买资源、存纪元、还是加速工程？ |
| 终盘 | 决战兵力配比？ | 碑盖哪（地基保护）？倒计时 90 秒怎么守？ |

**设计要点**：种田流在任何阶段都有"要做的事"和"要保护的软肋"（商队=移动钱包、碑=倒计时靶心），绝不出现挂机看海的空窗。

### 1.3 与现有流程的兼容性检查

- 胜负判定从 1 条（HQ）变 2 条（HQ / 加冕），结算画面加胜利方式标注。
- 满仓停机痛点被顺手治好：仓满 → 去市场卖余粮换金币（手动决策，不自动）。
- 中立生态不推倒：蛮族营地新增"通商中=停战"状态，剿灭缴获路线照旧，两条路收益互相牵制。
- **本方案全程不引入任何随机事件**：事件卡机制已于 v0.9.1 移除且不复返（与游戏主题不符，设计红线）。压力来源=蛮族劫掠、敌方 AI、加冕倒计时，全部是确定性威胁，不发牌。

## 二、金币系统（连接件，一切新经济的血管）

**定位**：不可开采、无存储上限的软通货。三资源管产能，金币管灵活性。

| 项 | 设计 | 借鉴来源 |
|---|---|---|
| 来源① | 商队贸易（主渠道，见 §三） | 帝国时代贸易车 / 文明商路 |
| 来源② | 市场出售盈余资源 | 文明（卖出过剩） |
| 去处① | 买资源（应急）："造不出来就用买" | 文明 |
| 去处② | 加速建造/科研（1金=2秒，每工地/科技限一次） | 文明购买 |
| 去处③ | 时代升级门票（§四） | 帝国时代升时代的资源门槛 |
| 去处④ | 奇观造价（§五） | 帝国时代奇观 |
| 上限 | **无上限**——它是满仓压力阀 | — |

**汇率（防套利是红线）**：
- 卖出：100 资源 → 40 金；买入：70 金 → 100 资源。中间 30 金差价保证"买了再卖"必亏，买是救火不是第二矿。
- 加速限一次：防止金币无限碾压建造时间，保留工程车建造流程的意义。

**AI 对等**：AI 商队收入与玩家同规则，难度经济倍率**不**作用于金币（贸易是活动收入，不是生产收入）。

## 三、商贸站与商队（方案3，金币的发动机，最先做）

### 3.1 建筑：商贸站
- 2×2，木80 食40，8秒，每家上限 2 座，**拓荒纪元即可建造**（种田开从第一分钟就有事干）。
- 功能：雇佣/管理商队；买卖资源面板。

### 3.2 单位：商队
- 雇价食30，每站最多 3 个，慢速（速度 40）无武装——**战场上的移动钱包**。
- 自动循环：驮货出发 → 中立营地交割 → 驮金返回，全程零指令（农夫链同款哲学）。

### 3.3 收益与路线
- 单趟收益 = **8金 + 2金/每10格路长，上限 24金**：近路稳而薄，远路肥而险，路线选择本身是核心决策。
- 路线渲染：复用集结点虚线画法，贸易动脉全图可见（己方才可见，敌方看不到你的路线，只看得到商队在跑）。
- 路线合法性：路径必须全程可走（陆路，高度感知）；目标营地被剿灭 → 该商队自动改签最近营地，没有营地则待命。

### 3.4 蛮族联动的妙手
- **通商中的蛮族营地停止劫掠**（复用 neutral.ts 现成的停战机制，贸易即纳贡）。
- 于是处置蛮族有两条路：出兵剿（拿一次性缴获）或通商养（持续金币 + 和平）。两账自平：剿=理财一次性，养=细水长流，互不碾压。

### 3.5 零代码红利
- 商队是普通地面单位：自动索敌系统让狼群会咬它、敌军顺手宰它、撤退战术会放过它——**对抗性全白送**。
- 敌方"断矿流"战术自然延伸为"断商流"（AI选靶权重加一项，纯数据）。

## 四、纪元晋升（方案2，种田流的骨架）

三纪元贴钢铁联邦皮：**拓荒纪元 → 工业纪元 → 钢铁纪元**（晨曦王国将来镜像为：学徒/高塔/大魔导）。

| 纪元 | 升级代价 | 时长 | 效果 |
|---|---|---|---|
| 拓荒（开局） | — | — | 全部现有内容；可建商贸站、跑商队 |
| 工业纪元 | 木400 食300 **金100** | 40s | 采集+5%、建造+10%；获得**奇观建造资格** |
| 钢铁纪元 | 木800 食600 矿400 **金300** | 60s | 采集+5%、伤害+5%；**解锁纪元纪念碑** |

- **实现走现成科研管线**：纪元 = 特殊科技，进研究所队列，永久生效。`world.mult` 新增"纪元乘数"来源，与法令/科技叠乘——管线现成，接水龙头。
- **软锁决策（重要）**：v1 时代只锁新内容（商队拓荒就有、奇观资格 2 纪元、奇观本体 3 纪元），**不硬锁任何现有建筑/兵种**。硬锁（坦克 2 纪元才能出之类）是伟大的调味料也是伟大的平衡灾难，列入开放问题，跑顺了再上。
- **AI 纪元节奏**（性格驱动，纯数据）：种田性格快升（约 4 分钟工业），均衡 6~8 分钟，乌龟 8~10 分钟，莽夫缓升甚至不升（军事流不需要纪元）。

## 五、纪元纪念碑（方案1，终局压轴）

- **建筑**：3×3，**木1500 食1200 矿1000 金400**，建造 180 秒（吃建造乘数），血量 ≥ HQ，钢铁纪元解锁，每家限一座。
- **胜利判定**：落成后进入 **90 秒"加冕倒计时"**，走完即胜；期间被拆则奇观报废（可重盖，投入沉没）。现有"拆 HQ 胜"不变。
- **90 秒是整个方案的戏剧核心**：AI 获得明确的翻盘窗口，双方目光聚焦那座碑——帝国时代奇观战的经典心跳。
- **造价账本（平衡的自洽性）**：和平路线全程金币支出 = 100（工业）+ 300（钢铁）+ 400（碑）= 800 金。按双商贸站 6 商队约 1.6金/秒 ≈ 9~13 分钟贸易积累（含商队购置期）——**奇观必须比推 HQ 慢**，这是军事流与种田流平衡的锚点；同时倒计时给军事流一个明确的"去拆它"窗口，双方都有事干。

## 十、风险与护栏

1. **汇率套利**：买卖差价 30 金锁死；任何后续调汇率必须先验证"买 卖 循环必亏"。
2. **金币碾压时间**：加速限一次已防；严禁出现"纯金币速推"路径（开新加速用途前先算账）。
3. **奇观龟缩必胜**：锚点公式——奇观全程耗时要明显慢于极限 rush 推 HQ；AI 反奇观必须在 selftest 里验证"倒计时内必来拆"，否则奇观=白给胜利。
4. **商队路线穿敌营**：路线合法性校验（可走格）+ 目标失联自动改签；商队太脆导致贸易完全玩不了 → 调血量而非速度。
5. **剿蛮 vs 养蛮失衡**：两账自平原则——剿=一次性缴获（现值），养=持续金币+停战；数值改动时两列一起调。
6. **满仓卖粮滚雪球**：卖是手动决策不自动，且卖价低于买价，不会被用成第二收入引擎。
