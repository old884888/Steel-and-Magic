# 钢铁与魔法（Steel & Magic）项目总览

> 致敬《铁锈战争》(Rusted Warfare) 的 2D 即时战略游戏。玩法机制像素级致敬，美术/设定/命名全部原创。
> 当前版本 **v0.6**：科技联邦阵营完整可玩 + AI指挥官系统 + 高地地形 + 地图生态。全AI开发。

## 快速开始

```bash
npm install     # 首次安装依赖
npm run dev     # 启动开发服务器（默认 http://localhost:5173）
npm run build   # 类型检查 + 生产构建
```

- 游戏：浏览器打开 `http://localhost:5173`，主菜单点"开始游戏"
- 无头自测：`http://localhost:5173/?selftest=1`（AI对打+日志断言，控制台看报告）
- AI锦标赛：`node tools/tournament.mjs`（需先 `npx esbuild tools/tournament.ts --bundle --format=esm --platform=node --outfile=tools/tournament.mjs`）

## 操作方式

| 操作 | 效果 |
|---|---|
| 左键点击 / 拖框 | 选中单位 |
| **双击单位** | 选中屏幕内全部同类单位 |
| 右键点击地面 | 移动 |
| 右键点击敌人 | 攻击 |
| **A + 左键** | 攻击移动（途中主动交战） |
| **S / H** | 停止 / 原地驻守 |
| **Ctrl+1~9 / 1~9** | 设置编队 / 选择编队 |
| 右键点击树木 / 矿脉 | 工程车砍树/挖矿（自动循环采集） |
| 右键点击鹿 / 蛮族 | 狩猎 / 攻击（缴获资源） |
| 右键点击己方受损建筑 | 工程车修理 |
| 选中单位 | 显示射程圈/视野圈（火炮含最小射程圈） |
| 选中工程车 → 面板按钮 | 建造模式，左键放置 |
| WASD / 方向键 / 中键拖拽 | 平移镜头 |
| 滚轮 | 缩放（以光标为中心） |
| 小地图点击/拖动 | 跳转镜头 |
| Esc / 右键 | 取消当前模式 |
